# Jejak Hijrah

Langkah demi langkah mengingat Allah.

(Sebelumnya: Program Hafalan Juz 30)

Aplikasi pribadi untuk menghafal Juz 30, mendengarkan murattal, serta dzikir pagi–petang dan setelah shalat.

- Teks Al-Qur'an & terjemahan Kemenag: Tanzil / quran-json (CC BY-SA 4.0)
- Murattal: Syaikh Mishary Rasyid Al-Afasy (The-Quran-Project)
- Dzikir: susunan Ustadz Yazid bin Abdul Qadir Jawas & Hisnul Muslim; teks dari fitrahive/dua-dhikr (MIT)

Data pribadi tidak disimpan di repositori ini. Data tersimpan di perangkat masing-masing,
dan (jika disambungkan) di gist privat milik akun pemilik.
